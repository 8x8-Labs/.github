<h3>익숙한 것에서 새로운 즐거움을 발견하는 경험을 모두에게.</h3>

</div>

<br clear="left">

---

**8x8 Labs**는 누구나 한 번쯤 접해본 보드게임과 퍼즐에 새로운 컨텐츠를 더해, 기존 팬과 신규 유저 모두에게 색다른 경험을 선사하는 **3인 게임 스튜디오**입니다.

우리의 목표는 단순히 "컨텐츠가 추가된 게임"을 만드는 것이 아닙니다.
오래된 팬에게는 더 깊은 재미를, 처음 접하는 이들에게는 새로운 흥미를 전달하여 클래식한 장르 자체를 더욱 풍성하게 부흥시키는 것 — 그것이 8x8 Labs가 추구하는 방향입니다.
